# Lesson 01: Introduction to LLM APIs

## Learning Objectives

In this lesson, we will learn how to interact with a Large Language Model (LLM) programmatically using Python and the OpenAI API.

By the end of this lesson, you should be able to:

- Understand the difference between using ChatGPT and calling an LLM through an API.
- Create and configure an OpenAI API client.
- Send prompts to an LLM using the Responses API.
- Extract generated text and inspect response metadata.
- Understand the basics of API authentication and token usage.

## 1. What is an LLM API?

A Large Language Model (LLM) is a machine learning model trained to process and generate language.

An Application Programming Interface (API) allows software applications to interact with an LLM programmatically.

Rather than entering questions manually through the ChatGPT interface, we can write Python programs that send requests to an LLM and process the responses.

The general workflow is:

**Python application → OpenAI API → LLM → API response → Python application**

The model typically runs on remote infrastructure rather than on the user's computer.

## 2. Environment Setup

This tutorial requires Python and an OpenAI API key.

Install the required Python packages:

```bash
python -m pip install openai python-dotenv
```

Create an API key through the [OpenAI Platform](https://platform.openai.com/api-keys).

Store the key in an environment variable called `OPENAI_API_KEY`.

Alternatively, create a `.env` file in your project directory containing:

```text
OPENAI_API_KEY=your_api_key_here
```

Keep this file private and exclude it from version control. OpenAI API usage may incur charges.

## 3. Making Your First API Call

Open `basic_api.py`.

The script imports the OpenAI client, loads the API key, sends a prompt to a model, and prints the generated response.

The most important instruction is:

```python
response = client.responses.create(
    model="gpt-5-mini",
    input="Write a one-sentence bedtime story about a unicorn."
)
```

Here:

- `client.responses.create()` invokes the Responses API.
- `model` identifies which model should process the request.
- `input` contains the instruction sent to the model.
- `response` stores the returned response object.

The generated text is accessed using:

```python
print(response.output_text)
```

Run the example from this directory using:

```bash
python basic_api.py
```

The output should be a short, model-generated story. The exact wording may vary between executions.

## 4. Inspecting API Responses

An API response contains more than just generated text.

Run:

```bash
python inspect_response.py
```

This example displays the model response, response identifier, model name, completion status, and token usage.

Tokens are units of text representation used by language models. API usage and pricing depend on the model and the number and types of tokens processed.

Monitoring token usage is useful when evaluating LLM applications for computational efficiency and cost.

## 5. LLM API Versus AI Agent

The examples in this lesson make direct calls to an LLM.

They do not yet implement an agent capable of calling external Python functions or performing multi-step workflows.

In later lessons, we will use the OpenAI Agents SDK to allow an LLM to select statistical tools, execute computations, and interpret their results.

## 6. Exercises

1. Change the prompt to ask a statistical question.
2. Compare the responses generated by two available models.
3. Inspect the token usage for prompts of different lengths.
4. Run the same prompt several times and observe any variation in the outputs.

## 7. Key Takeaways

- The OpenAI Python SDK provides a convenient interface to hosted LLMs.
- The Responses API returns structured response objects.
- API authentication is handled through credentials such as `OPENAI_API_KEY`.
- Model-generated text should not automatically be treated as factually or numerically correct.
- Direct LLM calls are a foundation for building more sophisticated Agentic AI systems.
